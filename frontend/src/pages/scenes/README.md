# 场景应用

场景应用只展示并办理已有 `IndustryCase`，不提供线索登记入口；线索保留原有授权范围，以复核、移交、处置、复查、归档推进。数据成果详情的“标记为疑似线索”操作会从关联任务创建待复核案件、保留任务关系并将原附件关联为线索证据，然后通过导航上下文打开该案件。牍术飞行照片只有在用户明确标记后才形成线索，并以 `source_media_link` 保存来源设备和媒体编号、任务及线索引用；图片仍保存在牍术，不复制进本地附件目录。现场上传仍通过 `/api/v1/attachments` 绑定 `caseId`；任务附件绑定 `taskId`。统一附件目录提供资源管理的数据成果页，因此本地文件的预览、质检、归档与共享状态跨页面一致。

页面展示本地保存且可追溯的附件和线索履历，也读取已明确关联的来源照片引用。来源识别观测不能仅凭设备或时间自动关联至线索。线索详情通过 `/api/v1/source-data/flight-photos/cases` 读取照片，并由本平台预览代理显示；照片仍受来源媒体文件可达性影响。数据成果快捷入口通过导航上下文打开媒体档案，并以线索名称进行元数据搜索。
